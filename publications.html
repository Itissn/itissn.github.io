Publications

My publications focus on automated algorithm design, genetic programming guided local search, curriculum learning, and large-scale vehicle routing problems.

For the most up-to-date publication list, please visit my Google Scholar profile .

Published Papers

Genetic Programming Guided Local Search for Large-Scale Vehicle Routing Problems

Status: Published in PPSN.

This work proposes GPGLS, a genetic programming guided local search framework for large-scale vehicle routing problems. Genetic programming is used to automatically design utility functions that guide the local search process.

Curriculum Learning for Genetic Programming Guided Local Search

Status: Published in CEC.

This work studies predefined curriculum learning strategies for improving the training process of GPGLS on large-scale vehicle routing problems.

Adaptive Curriculum Learning for Genetic Programming Guided Local Search

Status: Published in EvoStar.

This work develops adaptive curriculum strategies that use training performance to control curriculum transitions and reduce unnecessary training generations.

Submitted and Ongoing Manuscripts

Instance Space Analysis for Large-Scale Vehicle Routing Problems

Status: Submitted to PPSN.

This work analyses the relationship between instance features and constructive heuristic performance for large-scale vehicle routing problems.

Dynamic Curriculum Learning for GPGLS

Status: Submitted to PPSN.

This work studies online dynamic curriculum learning for GPGLS by estimating instance difficulty from solver feedback and observed optimality gaps.

Behaviour Niching in GPGLS

Status: Research in progress.

This work investigates behaviour-based niching for maintaining behavioural diversity among GP trees and controlling unnecessary tree complexity.

Surrogate-Assisted GPGLS

Status: Research plan in preparation.

This work explores surrogate-assisted training strategies to reduce expensive GPGLS fitness evaluations.
