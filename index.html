About Me

I am a PhD candidate in Computer Science at Victoria University of Wellington, New Zealand. My research focuses on automated algorithm design for large-scale vehicle routing problems, with particular interests in evolutionary computation, genetic programming, guided local search, curriculum learning, and lifelong learning for neural combinatorial optimization solvers.

My work aims to develop adaptive and learning-based optimization methods that improve the efficiency, scalability, and generalization ability of routing solvers under complex and dynamically changing problem settings.

Research Interests

Large-Scale Vehicle Routing Problems

Scalable optimization methods for routing problems involving large numbers of customers, complex constraints, and challenging search spaces.

Automated Algorithm Design

Automatic design and adaptation of algorithmic components based on problem-solving experience and search feedback.

Genetic Programming Guided Local Search

Genetic programming methods for evolving utility functions that guide local search for large-scale vehicle routing problems.

Curriculum Learning

Training strategies that control the order, difficulty, and diversity of routing instances to improve solver learning efficiency.

Lifelong Learning

Neural combinatorial optimization solvers that continually adapt to new routing patterns while reducing catastrophic forgetting.

Instance Space Analysis

Analysis of how instance features relate to algorithm performance and where different routing heuristics succeed or fail.

Selected Projects

Genetic Programming Guided Local Search for LSVRPs

This project studies how genetic programming can automatically design utility functions for guided local search, aiming to improve the performance of heuristic search on large-scale vehicle routing problems.

Curriculum Learning for Routing Solvers

This project investigates curriculum learning strategies for improving the training efficiency and robustness of routing solvers by controlling training instance difficulty and diversity.

Lifelong Learning for Neural Routing Solvers

This project explores how neural solvers can continually learn from newly emerging routing patterns while maintaining previously acquired knowledge.

Instance Space Analysis for Constructive Heuristics

This project uses instance space analysis to understand the relationship between vehicle routing instance features and the performance of constructive heuristics.
