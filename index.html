About Me

I am a PhD candidate in Computer Science at Victoria University of Wellington, New Zealand. My research focuses on learning-based and evolutionary approaches for solving large-scale vehicle routing problems.

Research Interests

  • Large-scale vehicle routing problems
  • Genetic programming guided local search
  • Curriculum learning for combinatorial optimization
  • Lifelong learning for neural routing solvers
  • Instance space analysis

Selected Projects

GPGLS for Large-Scale Vehicle Routing Problems

This project studies genetic programming-guided local search for automatically designing utility functions for large-scale vehicle routing problems.

Lifelong Learning for Neural Routing Solvers

This project investigates how neural solvers can continually adapt to newly emerging routing patterns while mitigating catastrophic forgetting.
