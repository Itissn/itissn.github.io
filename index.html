About Me

I am a PhD candidate in Computer Science at Victoria University of Wellington, New Zealand. My research focuses on automated algorithm design for large-scale vehicle routing problems, with particular interests in genetic programming, guided local search, curriculum learning, instance space analysis, behaviour niching, and surrogate-assisted evolutionary computation.

My PhD research investigates how learning-based and evolutionary approaches can improve the design, training efficiency, robustness, and scalability of heuristic search methods for large-scale vehicle routing problems.

Research Interests

Large-Scale Vehicle Routing Problems

Scalable optimization methods for vehicle routing problems with large numbers of customers, complex search spaces, and practical computational constraints.

Automated Algorithm Design

Automatic design and adaptation of heuristic search components for large-scale routing problems, reducing the reliance on manually crafted search rules.

Genetic Programming Guided Local Search

Genetic programming approaches for evolving utility functions that guide local search using instance, solution, and edge-level features.

Curriculum Learning for GPGLS

Curriculum-based training strategies that improve GPGLS by controlling the order, difficulty, and diversity of training instances.

Instance Space Analysis

Analysis of how vehicle routing instance features relate to constructive heuristic performance and learned search guidance.

Behaviour Niching and Surrogate Assistance

Diversity preservation and surrogate-assisted training methods for improving the robustness and efficiency of GPGLS under expensive fitness evaluations.

Selected Projects

Instance Space Analysis for Large-Scale Vehicle Routing Problems

This project analyses the relationship between instance features and the performance of constructive heuristics for large-scale vehicle routing problems. It provides an instance-space understanding of when and why different constructive heuristics succeed or fail.

Status: submitted to PPSN.

Genetic Programming Guided Local Search for LSVRPs

This project develops GPGLS, where genetic programming automatically designs utility functions for guided local search using instance, solution, and edge features as terminals.

Status: published in PPSN.

Curriculum Learning and Adaptive Curriculum Learning in GPGLS

This project studies curriculum-based training strategies for GPGLS. It first applies predefined curriculum learning to GPGLS, and then develops adaptive strategies that use training performance to control curriculum transitions and reduce the number of training generations.

Status: CL-GPGLS published in CEC; ACL-GPGLS published in EvoStar.

Dynamic Curriculum Learning for GPGLS

This project develops an online dynamic curriculum learning framework for GPGLS. It estimates instance difficulty from observed optimality gaps and uses solver performance feedback to guide curriculum selection under limited computational budgets.

Status: submitted to PPSN.

Behaviour Niching in GPGLS

This ongoing project investigates behaviour-based niching for GP trees. It studies how behavioural diversity can be maintained during evolution and how smaller trees can be preferred among behaviourally similar individuals to improve robustness and control unnecessary complexity.

Status: research in progress.

Surrogate-Assisted GPGLS

This planned project studies how surrogate models can reduce expensive GPGLS fitness evaluations and improve training efficiency. The project may involve GP individual characterisation, surrogate-assisted selection, and experimental analysis under limited computational budgets.

Status: research plan in preparation.
